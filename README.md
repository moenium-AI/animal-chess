# 🐱 Animal Chess

Animal Chess is a friendly browser chess game with cute animal pieces. No installation is required.

## 🎮 Play

👉 **https://moenium-ai.github.io/animal-chess/**

Open the link and start playing. It works on both phones and desktop computers.

## ✨ Features

- **3D pixel-art mode** — Anthropomorphic animal characters with idle animations.
  - 🐤 Pawn = chick / 🐴 Knight = horse / 🦉 Bishop = owl / 🐻 Rook = bear / 🐱 Queen = cat / 🦁 King = lion
  - Captured pieces ride a pixel-art carriage to the opposing team's **banquet hall**, where they eat 🍖, drink 🍺, and relax 💤 in real time.
- **Simple mode** — Switch to emoji-based pieces, including the classic set and four animal sets.
- **Piece badges** — Show ♟♞♝♜♛♚ in the corner of each piece so its type is always clear. Toggle them on or off.
- **🎵 BGM** — Ten gentle original songs. Play them in order with Auto mode or loop one favorite song. Toggle BGM on or off.
- **Computer opponent** — Strength levels 1–10, with opening knowledge, endgame technique, and tactics introduced gradually. The levels are tuned to stay approachable.
- **Two-player mode** — Take turns on the same screen.
- **💡 Hints** — The AI suggests a move and explains why it is useful.
- **🎓 Learn** — Study openings, combinations, and endgames one move at a time with original annotations.
- **🌐 Japanese / English** — Switch languages from the menu in the upper-right corner. The choice is saved in the browser.
- **🏆 Famous games** — Replay historic games with original move-by-move notes. Every move is machine-checked.
- **📜 PGN loading** — Paste or load a PGN file, click any move to replay from that point, and resume a game from the selected position.
- **🧩 Chess puzzles** — 38 puzzles in mate-in-1, mate-in-2, and mate-in-3 formats. Filter by difficulty (⭐–⭐⭐⭐) or by learning theme such as back rank, fork, diagonal attack, two rooks, endgame, sacrifice, and opening trap. Each puzzle includes an explanation of its idea.

The game makes no external network requests. Settings and puzzle progress are stored in the browser's `localStorage`.

## ✨ 機能

- **3Dモード（ドット絵）** — 待機モーション付きの擬人化どうぶつキャラクター。
  - 🐤 ポーン＝ひよこ / 🐴 ナイト＝うま / 🦉 ビショップ＝ふくろう / 🐻 ルーク＝くま / 🐱 クイーン＝ねこ / 🦁 キング＝ライオン
  - 取られたコマはドット絵の馬車で相手チームの**宴会会場**へ移動し、食べたり🍖、飲んだり🍺、寝転んだり💤しながらリアルタイムで過ごします。
- **シンプルモード** — 絵文字ベースのコマに切り替えます。クラシックセットと動物セット4種類を収録しています。
- **コマ種類バッジ** — コマの隅に♟♞♝♜♛♚を表示し、種類をいつでも確認できます。表示・非表示を切り替えられます。
- **🎵 BGM** — やさしいオリジナル曲を全10曲収録。「オート」で順番に流すか、好きな1曲をループできます。ON/OFF切り替えにも対応しています。
- **コンピューター対戦** — 強さはレベル1〜10。オープニング定跡・終盤の寄せ・戦術を段階的に使用し、強すぎない範囲に調整しています。
- **ふたりで遊ぶ** — 同じ画面で交互に操作できます。
- **💡 ヒント機能** — AIが次の一手と、その手が有効な理由を説明します。
- **🎓 まなぶ** — オープニング定跡・コンビネーション（戦術）・エンドゲームを、独自解説付きで一手ずつ学べます。
- **🌐 日本語 / English** — 画面右上の言語メニューから切り替えられます。設定はブラウザ内に保存されます。
- **🏆 名局** — 歴史的な名勝負を独自の一手解説付きで鑑賞できます。すべての指し手を機械検証済みです。
- **📜 棋譜（PGN）読み込み** — 貼り付け・ファイル読み込みに対応。手をクリックして任意の位置から再生し、選んだ局面から対局を再開できます。
- **🧩 チェスパズル** — 1手詰め・2手詰め・3手詰めの全38問。難易度（⭐〜⭐⭐⭐）と、バックランク・フォーク・斜め・二枚のルーク・エンドゲーム・サクリファイス・定跡の罠などの学習テーマで絞り込めます。各問に狙いの解説があります。

外部への通信は一切ありません。設定とパズルのクリア状況はブラウザ内の `localStorage` に保存されます。
