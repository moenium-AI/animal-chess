# 🐱 Animal Chess

Animal Chess is a friendly browser chess game with cute animal pieces. No installation is required.

## 🎮 Play

👉 **https://moenium-ai.github.io/animal-chess/**

Open the link and start playing. It works on both phones and desktop computers.

## ✨ Features

- **Miniature mode** — Detailed animal figurines on a maple/walnut board, with timber dining rooms, miniature furniture, food, and a wooden carriage. Crowns, ears, and bases stay inside each square, including when selected. Red/ivory and navy/walnut distinguish the teams.
  - 🐤 Pawn = chick / 🐴 Knight = horse / 🦉 Bishop = owl / 🐻 Rook = bear / 🐱 Queen = cat / 🦁 King = lion
  - Captured pieces ride a carriage to the opposing team's **banquet hall**, where they eat 🍖, drink 🍺, and relax 💤 in real time.
- **Pixel art mode** — The original animal characters, furniture, food, and carriage remain available alongside Miniature mode. Change graphics during a game without losing the position or move history.
- **Simple mode** — Switch to emoji-based pieces, including the classic set and four animal sets.
- **Piece badges** — Show ♟♞♝♜♛♚ in the corner of each piece so its type is always clear. Toggle them on or off.
- **🎵 BGM** — Ten gentle original songs. Play them in order with Auto mode or loop one favorite song. Toggle BGM on or off.
- **Computer opponent** — Strength levels 1–10, with opening knowledge, endgame technique, and tactics introduced gradually. The levels are tuned to stay approachable.
- **Two-player mode** — Take turns on the same screen.
- **💡 Hints** — The AI suggests a move and explains why it is useful.
- **🎓 Learn** — Follow an 80-lesson course across basics, strategy, tactics, endgames and openings, plus a sixth **Famous Games** chapter with 15 annotated historic games. Practise a move on the real board in all 80 lessons, track learning/viewing progress in the browser, and open related puzzles. In 12 selected lessons you can compare the demonstrated move with a curated alternative on the same replay board, with bilingual explanations of concrete consequences.
- **🌐 Japanese / English** — Switch languages from the menu in the upper-right corner. The choice is saved in the browser.
- **🏆 Famous games** — Find 15 annotated historic games under Learn, instead of the game-record tabs. All move sequences are machine-checked; historical attribution is a separate editorial check.
- **📜 PGN loading** — Paste or load a PGN file, click any move to replay from that point, and resume a game from the selected position.
- **🧩 Chess puzzles** — 80 puzzles: 42 forced-mate exercises (1–3 moves) and 38 one-move tactical/rules challenges. Filter by difficulty (⭐–⭐⭐⭐) or by learning theme such as back rank, fork, pin, skewer, discovered attack, double check, promotion, en passant, stalemate avoidance, diagonal attack, two rooks, endgame, sacrifice, and opening trap. Each puzzle includes an explanation of its idea. After clearing a puzzle, a **Next puzzle** button continues to the next unfinished puzzle in the current filter (or the following section), without jumping back to the first puzzle. The puzzle list preserves its scroll position.

The game makes no external network requests. Settings and puzzle progress are stored in the browser's `localStorage`.

## ✨ 機能

- **ミニチュアモード** — 精細な動物の駒と、メープル・ウォールナット調の盤。木造の食堂、家具、ごちそう、木製の馬車で雰囲気を揃えています。選択中も王冠・耳・台座がマス内に収まります。赤とアイボリー、紺と濃い木色でチームを区別できます。
  - 🐤 ポーン＝ひよこ / 🐴 ナイト＝うま / 🦉 ビショップ＝ふくろう / 🐻 ルーク＝くま / 🐱 クイーン＝ねこ / 🦁 キング＝ライオン
  - 取られたコマは馬車で相手チームの**宴会会場**へ移動し、食べたり🍖、飲んだり🍺、寝転んだり💤しながらリアルタイムで過ごします。
- **ドット絵モード** — 以前の動物の駒・家具・ごちそう・馬車も選べます。対局中にグラフィックを変えても、局面と棋譜は保持されます。
- **シンプルモード** — 絵文字ベースのコマに切り替えます。クラシックセットと動物セット4種類を収録しています。
- **コマ種類バッジ** — コマの隅に♟♞♝♜♛♚を表示し、種類をいつでも確認できます。表示・非表示を切り替えられます。
- **🎵 BGM** — やさしいオリジナル曲を全10曲収録。「オート」で順番に流すか、好きな1曲をループできます。ON/OFF切り替えにも対応しています。
- **コンピューター対戦** — 強さはレベル1〜10。オープニング定跡・終盤の寄せ・戦術を段階的に使用し、強すぎない範囲に調整しています。
- **ふたりで遊ぶ** — 同じ画面で交互に操作できます。
- **💡 ヒント機能** — AIが次の一手と、その手が有効な理由を説明します。
- **🎓 まなぶ** — 全80教材（入門14・基本戦略10・戦術21・終盤18・定跡17）と、独立した第6章「名局」15局。すべての教材で盤面を操作して一手を再現でき、学習・習得・鑑賞履歴をブラウザに保存。関連パズルへも移動できます。 厳選した12教材では、教材の手と別の合法手を同じ盤面で切り替え、日英の解説を読みながら違いを学べます。
- **🌐 日本語 / English** — 画面右上の言語メニューから切り替えられます。設定はブラウザ内に保存されます。
- **🏆 名局** — 「まなぶ」の中で歴史的な15局を一手解説付きで鑑賞できます。棋譜の合法性は検証済みですが、すべての原棋譜・史実の完全照合は別の編集作業です。
- **📜 棋譜（PGN）読み込み** — 貼り付け・ファイル読み込みに対応。手をクリックして任意の位置から再生し、選んだ局面から対局を再開できます。
- **🧩 チェスパズル** — 1手詰め・2手詰め・3手詰めの詰み42問と、1手で完成する戦術・特殊ルール38問の合計80問。難易度（⭐〜⭐⭐⭐）と、バックランク・フォーク・斜め・二枚のルーク・エンドゲーム・サクリファイス・定跡の罠などの学習テーマで絞り込めます。各問に狙いの解説があります。クリア後は「次の問題へ」で、現在の問題より後にある未クリア問題へ進めます。絞り込みの最後なら次の分野へ移り、問題一覧のスクロール位置も維持します。

外部への通信は一切ありません。設定とパズルのクリア状況はブラウザ内の `localStorage` に保存されます。

### Puzzle catalog maintenance / パズルの管理

Edit `tools/puzzle_catalog.json`, then run `node tools/build_puzzles.cjs` to regenerate both language files (`js/puzzles.js`, `js/puzzle_en.js`). Run `node tools/build_puzzles.cjs --check`, `node tools/test_puzzle_quality.cjs`, `node tools/test_mate_solver.cjs`, `node tools/test_extended_tactics.cjs`, and `node tools/test_learning_runtime.cjs` before shipping. To prevent false negatives for alternative correct tactics, also run `node tools/audit_alternate_tactics.cjs` and `node tools/test_puzzle_alternatives.cjs`; optional browser smoke test: `python tools/test_puzzle_alternatives_browser.py`. Puzzle navigation also has `node tools/test_puzzle_navigation.cjs` and an optional Chromium/Playwright test, `python tools/test_puzzle_navigation_browser.py`. Optional: `python tools/verify_puzzles.py` with `python-chess` installed for an independent solver implementation.

パズルの正本は `tools/puzzle_catalog.json` です。問題拡張の変更内容は `docs/puzzle-expansion-2026-10-17.md`、別解の誤判定修正と検証範囲は `docs/puzzle-answer-audit-2026-10-17.md` を参照してください。旧クリア履歴との互換性はありません。既存の記録は読み込まず、今回の版のクリア状況だけを `animalchess_solved_v4` に保存します。

## AI search reliability and balance (2026-10-24)

The engine now validates checked quiescence leaves, searches 3-fold repetitions and the
50-move condition, uses full-window scores at the root, and never disables its deadline.
The 10 level knobs have been conservatively retuned; small-sample play remains non-monotonic.
See [analysis and limitations](docs/engine-search-and-balance-2026-10-24.md) and
[5-position Stockfish 16 review](docs/ai-balance-recheck-2026-10-24.json).
Run `node tools/test_engine_search.cjs` to check new search edge cases.

## Mirrored AI self-play tournament (2026-10-24)

Use `node tools/tournament_ai_levels.cjs --pair-mode adjacent --opening-indices 0,2,4,6,8,10 --budget-scale 0.12 --max-plies 96 --output matches.json` to reproduce a **short-budget** paired-color tournament. Runs can be restricted with `--only-pair 8-9`; cross-tier tests use `--pair-mode cross`. Group games by the opening/seed pair for uncertainty estimates with `node tools/summarize_ai_tournament.cjs matches.json`.

This diagnostic has a strict ply cap and shortened search budgets. Resulting Elo-like differences are **not ratings at normal game settings**. Any games reaching the limit remain explicitly marked as unfinished and are scored as draws only under this particular tournament rule. See [the self-play results](docs/ai-selfplay-2026-10-24.md). The original difficulty settings were retained because the confidence intervals do not justify a forced recalibration.

## AI level 5–8 conservative calibration (2026-10-24)

The mid-level AI move-selection variability was tightened without changing search depth or CPU-time budget; levels 1–4 and 9–10 remain unchanged. A nine-position paired Stockfish 16 study, with both previous and new settings at full budget, found level 5 mean score loss 116cp → 81cp; levels 6 and 8 selected identical moves, while level 7 changed 83cp → 81cp. **This is not a rated Elo improvement**. A 12-game reduced-time pilot had only 3 decisive games and does not establish monotonic strength. See [calibration findings](docs/ai-calibration-2026-10-24.md), [raw comparisons](docs/ai-calibration-2026-10-24.json) and [pilot games](docs/ai-calibration-pilot-2026-10-24.json). Run `node tools/test_ai_calibration.cjs` for data/level regression checks.
