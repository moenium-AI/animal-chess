# 動物チェス：キング・クイーン・ポーンの制作直前ラフスプライト指示書

> **実装後の更新:** この文書は当初の40×52pxラフ設計。PR #43の採用済みロイヤル画像は96×124pxを実際の元素材規格とする。残り3駒（クマ・フクロウ・馬）は [新仕様](pixel-royal-rook-bishop-horse-art-spec-2026-10-26.md) を優先し、この旧座標をそのまま流用しない。

**版:** 2026-10-26 / Art direction v1.0  
**対象:** ドット絵モードのみ（内部 viewMode = '3d'）  
**状態:** 制作仕様。新しい完成スプライトを追加したものではない。実機相当の描画サイズで承認してから置換する。

## 1. 目指すもの・守るもの

過去のラフ絵で好評だった「丸くて愛らしい顔、短い体、温かな表情、可愛い王族衣装」を、チェスとして読める大きさに整理する。**前回の機械的な40×52ドット化を正解としない。顔とシルエットから描き直す。**

- 盤面の8×8マスと真上からの見え方は維持。駒単体はやや上から見た**正面寄り3/4表現**で、顔・頭頂の冠・足元を同時に見せる。盤面を傾けない。
- 取られた動物は、従来どおり**馬車に乗り、宴会会場に到着し、飲食・散歩・まばたき・睡眠**をする。動物の種類と陣営も維持。
- 駒の種類を見分けるための大きな形は、キング＝たてがみと王冠、クイーン＝立ち耳と小冠とドレス、ポーン＝小さく丸いヒヨコ。
- 可愛さを作る順序は **顔の輪郭 → 目と口 → 耳・たてがみ → 頭身 → 服飾**。宝石・模様の量でごまかさない。
- 過剰な黄色い照明、発光、細かな装飾、ランダムなディザ、1pxの輝点は不要。光は柔らかな左上から一方向。背景は追加しない。
- 6種類のキャラクターは現行どおりライオン(k)、ネコ(q)、クマ(r)、フクロウ(b)、シカ(n)、ヒヨコ(p)。この指示書では k/q/p のみ完成設計する。

## 2. 絶対座標とレイヤー

| 定義 | 値 |
| --- | --- |
| キャンバス | 40×52 ピクセル、RGBA8、背景は完全透明 |
| X座標 | 左 0 ～ 右 39。右に行くほど増加 |
| Y座標 | 上 0 ～ 下 51。下に行くほど増加 |
| 表の範囲表記 | x=13..27 は **両端を含む** 15px。指定範囲は完成目標のラフ枠 |
| 中心軸 | 原則 x=19.5。左右対称を厳密に強制しない |
| 接地 | 足底 y=46～47を基本。下側 y=48～51 は透明余白 |
| 安全域 | 外周2px程度を空ける。王冠・耳・手足で越えない |
| 形の優先順位 | 頭・顔が主役。顔を小物が横切らない |

描画順は **(1)ごく薄い足元の影 → (2)短い足・衣装 → (3)尻尾・耳の奥側 → (4)頭/たてがみ → (5)顔と目鼻 → (6)冠/宝飾**。冠は目を覆わない。

輪郭は1pxの濃い茶または青灰。黒100%で太く囲まない。面の基本は「影、地色、光が当たる面」の3階調まで。目の白点は各1pxで十分。彩度・ハイライトを強くしすぎない。

**表情:** 頼もしいが怖くない。大きく丸いたてがみ、短い手、やや下がった眉。目は垂れ気味、口元は小さな微笑み。王冠は一番わかりやすい識別点。

## 7. 宴会場を壊さない差分設計

現行ゲームの宴会場は**高さ64 CSS px**、動物Canvasの表示幅は**40 CSS px**。状態機械の idle / stroll / eat / drink / sleep と、既存のフードCanvas（meat, cake, mug, apple）がすでにある。新しい専用ポーズは**差し替え追加**にとどめる。

- 宴会 idle は盤上の通常姿を再利用可能。まず優先すべきは eat / drink / sleep。
- 上表にあるポーズの目・腕・翼だけを可変レイヤーにすれば、髪・耳・冠・たてがみの形が揺れず、統一感を保てる。
- 現行の眠りはCSSで**90°回転**する。新しく描いた sleep 素材を最初から横倒しにしてしまうと二重に回る。専用横臥スプライトへ切り替えるのは別の実装段階。
- eat / drink の料理やカップは現行の itemEl が重ねる。**ポーズ素材には料理自体を描き込まない**。余計な二重表示を避ける。
- 睡眠時に横長の絵が会場の端で切れないこと。端のゲストの x 位置には52px分の回転後の幅を考慮する。新しい家具・床・追加客は不要。
- 馬車から到着する前に会場へ出現させない。待った、盤面反転、モード切替、reduced-motion設定を既存の仕組みのまま維持。

## 8. 馬車の乗客：小さな専用半身スプライト

現行の js/sprites.js は馬車の乗客を **40×52 の全体から15×20へ縮小描画**しており（drawImage(source, 2, 0, 15, 20)）、身体の縮小で顔・表情が見えにくい。これはクロップではなく全身縮小である。正式版では乗客用の16×20 pxの**顔と上半身の専用素材**を作り、従来の小馬車キャンバスへ約15×20pxで描画する。

| 駒 | 16×20で残す情報 | 具体的な配置 |
| --- | --- | --- |
| キング | 王冠、丸いたてがみ、両目、ローズ／紺の襟 | 冠 x4..11 y1..5、顔とたてがみ x1..14 y4..15、服 x3..12 y14..19 |
| クイーン | 両耳、ティアラ、目、ドレスの色 | 耳 x1..5/11..15 y2..7、ティアラ x6..10 y1..5、顔 x3..12 y6..15 |
| ポーン | 丸い黄色い顔、くちばし、小型の帽子 | 帽子 x5..11 y2..5、顔 x2..13 y5..15、服 x5..11 y15..19 |

馬車側の上描きで y=12 以降の乗客が一部隠れる現行構成を前提に、**頭と目は表示先の y=0..11に収める**。体は荷台に隠れて構わない。馬車の位置・移動時間・前後方向・到着イベントは変更しない。

## 9. 素材命名・必要枚数

ファイル名の陣営記号 **w = 白、b = 黒**、駒記号 **k/q/p** はゲームの既存キーに合わせる。

正面通常 PNG の命名は既存の tools/check_pixel_hd_source.py と揃える：
- pieces/w_k_lion_king.png、pieces/b_k_lion_king.png
- pieces/w_q_cat_queen.png、pieces/b_q_cat_queen.png
- pieces/w_p_chick_pawn.png、pieces/b_p_chick_pawn.png

状態差分はたとえば poses/w_k_lion_king_blink.png、poses/w_k_lion_king_eat.png、poses/w_k_lion_king_drink.png、poses/w_k_lion_king_sleep.png。馬車の半身は riders/w_k_lion_king.png。黒と他2種も同規則で展開。

| 制作物 | 内訳 | 計 |
| --- | --- | ---: |
| 盤上通常 | 3役×2陣営 | 6 |
| 目閉じ | 3役×2陣営 | 6 |
| 宴会ポーズ | eat/drink/sleep × 3役×2陣営 | 18 |
| 馬車乗客 | 3役×2陣営 | 6 |
| **総制作枠** | idleは盤上通常を再利用 | **36枚** |

通常・目閉じ・宴会ポーズはすべて40×52のRGBA PNG。馬車用は16×20。**最初のレビューは通常6枚のみ**でよい。合格後に目閉じ・宴会・乗客を作る。

## 10. 実装に渡す際の注意

- 既存の js/pixel_hd.js は40×52の描画ロジック。新しい絵が合格するまでは**既存版をそのまま保持**する。描画系変更は別PRで行う。
- js/sprites.js にある charCanvas / makePiece / redrawPiece の呼び出し形は保持。新規アセットの読み込みに失敗したら元のセット全体へ戻す。
- このラフ指示書を座標ごとのピクセルチェックに機械翻訳して**固い幾何学図形にしてしまわない**。枠と識別要素は固定し、顔の曲線と1pxの不均一さは絵師の裁量で仕上げる。
- 実寸評価は「盤面320px幅」（1マス40pxのモバイル相当）、「盤面390px幅」、デスクトップで行う。盤上Canvasが各マスに実際表示される大きさで確認する。
- 白黒と明暗両マス、初期32体、拡大図、まばたき、ゲスト40px表示、馬車15px乗客、食べ物の重なりを確認する。
- 人間が**可愛いと感じるか**は自動テストだけで判定できない。デザイン採用は画面上の比較レビューで行う。

## 11. 作画担当への一枚要約

**ライオン王:** 「ふっくら顔・もこもこたてがみ・3山の王冠・小さな微笑み」。顔の幅19px前後、王冠は y5～15、目は y23～25。  
**猫の女王:** 「大きく立った猫耳・小さなティアラ・丸い頬・ゆるやかなAラインドレス」。耳は y10～22、顔は y17～35、ドレスは y32～46。  
**ヒヨコ歩兵:** 「小さく丸い黄色の体・つぶらな目・4px以内のくちばし・小さな帽子」。顔は y19～37、スカーフは y37～41。

共通で、**かわいさを足すために物を増やさない。顔を美しく整え、色面と余白で仕上げる。**

## 12. この文書の完成条件

- すべての役割に具体的な座標範囲と色が指定されている。
- 宴会・馬車版の固有シルエットが指定されている。
- 既存コードの表示寸法と、二重回転・料理の二重描画・馬車縮小という注意点が記録されている。
- 初回レビュー対象と製品反映の条件が分離されている。

次の作業は**通常姿のキング・クイーン・ポーンを白黒で6枚描く**こと。そのアート承認後にゲームへ組み込む。
