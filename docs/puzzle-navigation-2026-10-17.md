# パズルの次問案内の修正（1017_005）

## 原因

`puzzleSolved()` が `PUZZLES.findIndex` で「全問題の先頭から未クリア」を検索していたため、途中から解いた場合に、意図せず1手詰めの初期問題を次問として表示していた。また `renderPuzzleList()` がリストを空にして再生成するたびにスクロール位置を失い、リスト自体が先頭へ戻っていた。

## 改善内容

- **現在の問題より後ろ**にある未クリア問題だけを次問候補とする。先頭には巡回しない。
- まず現在の難易度・テーマのフィルターに該当する後続問題を探す。残っていなければ、カタログ上の後続問題へ進む（次の難易度・分野への移行）。この場合だけフィルターを「すべて」に戻して、移動先が一覧に表示されるようにする。
- 完了時にはタイトル付きの次問案内と **「▶ 次の問題へ」** ボタンを常時表示する。従来の一時的な次問トーストを廃止。自動では問題を切り替えない。
- 最後の問題まで進んだ場合は巻き戻さず、一覧から他の未クリア問題を選ぶよう案内する。全問クリア時は専用メッセージを表示する。
- 一覧の再描画時はスクロール位置を保つ。利用者がフィルターを変更した場合は先頭から表示する。「次の問題へ」での移動先は可視範囲にスクロールする。
- 新しい完了メッセージを日本語・英語へローカライズ。通常対局・棋譜再生への切り替え時は案内を隠す。

## テスト

- `node --check js/app.js` / `node --check js/i18n.js`
- `node tools/test_puzzle_navigation.cjs` （抽出した実ロジックを使った境界条件テスト）
- `python tools/test_puzzle_navigation_browser.py` （Playwright と Chromium が必要）。元のHTMLとJavaScriptを実ブラウザで実行し、途中からの次問選択・クリア済みスキップ・リストスクロール保持・1手詰めから2手詰めへの移動・最後の問題・英語翻訳を確認する。検証環境のブラウザは `file://` / HTTP アクセスが制限されるため、ローカルHTMLの内容を直接読み込む方式。
- 既存のパズル/戦術/学習/描画回帰テストの継続実行。

問題データ・解答データ・クリア記録のキーは変更していない。
