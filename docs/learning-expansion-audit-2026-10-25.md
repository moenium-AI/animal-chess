# 学習教材の再監査と拡張（2026-10-25）

## 変更点

- 名局15局を棋譜タブから「まなぶ」の第6章へ移設。独立した棋譜読み込み・この対局の機能は維持。
- 既存の44教材について、指し手の合法性、日本語・英語の手順一致、全注釈の存在を改めて自動検査する。旧来の教材データとそのIDは変更せず、段階別の復習に使用。
- 従来44教材に一手チャレンジを追加。定跡は代表的な序盤の展開手（最大5半手目）、戦術・終盤は最初の手を実演できる。あくまで**指定手の再現**であり、全別応手の最善性判定ではない。
- 新規12教材（定跡4、戦術4、終盤4）を日英で制作。既存の24件の入門・基本戦略教材も維持。
- 合計80教材：入門14＋基本戦略10＋戦術21＋終盤18＋定跡17。別枠の名局15局を加えた計95コンテンツ。
- `animalchess_learning_v1` の同じ保存先を利用し、新規教材と名局のIDを追加。以前の学習済み／習得済み記録は保持。名局は鑑賞済みのみ記録し、棋力「習得」と混同しない。

## 監査の根拠と限界

既存44教材の参照元は、10月15日の[監査](learning-audit-2026-10-15.md)と10月16日の[修正記録](learning-fixes-2026-10-16.md)。当時、271半手の合法性・SAN・翻訳手順を検査し、ルセナ、フィリドール、三角法を保存済みテーブルベースと照合して修正した。名局15局695半手についても合法な棋譜を検査した。

今回追加した `tools/test_course_expansion.cjs` は、従来44本を**再実行**して、全80教材の日本語・英語SANと注釈、80演習の合法性・正解判定・非破壊性、名局15局の全指し手、ID一意性、保存データの復元をチェックする。既存の `tools/test_intro_lessons.cjs` とブラウザの回帰検査も実施する。

**検証の限界**：棋譜が合法で、本文が空でなく、指し手が合っていることだけでは、説明した手順が全応手に対して最善であることは立証されない。既存教材の「型の実演」と「必然的に成功する戦術」は区別し、過去に見つかった反証に関する注意書きを保持する。過去に指摘したルセナ・フィリドール・三角法の修正内容は変更しない。原棋譜15局すべての史実・掲載元の照合と、旧教材のあらゆる変化についてのエンジン検証は未完了であり、誤って検証済みと表示しない。

## 操作と検証

- PC・スマホとも「まなぶ」内のカテゴリから名局を閲覧。棋譜の下側には「この対局」「よみこみ」の2タブを維持。
- 名局を最後まで閲覧すると「鑑賞済み」が保存される。
- 旧教材を選び「一手ためす」で代表手直前に戻り、棋盤で正しい手を再現すると「習得」に昇格する。
- 新12教材はそれぞれ個別の設問・ヒントと指し手解説を日本語・英語で用意。
- 全演習で実際の `Chess` 実装を用いて正誤を判定し、解答前の局面は壊さない。

```sh
node tools/test_intro_lessons.cjs
node tools/test_course_expansion.cjs
python tools/test_full_game_browser.py
```

棋譜生成元 `tools/lessons_gen.py` と `tools/games_gen.py` は変更せず、以前のZIPからの上書きは行わない。
