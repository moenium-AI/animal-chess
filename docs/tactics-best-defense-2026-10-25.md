# 対最善防御の戦術教材改訂（2026-10-25）

## 結果と根拠

改訂対象：`cb_windmill`（風車）。前段階のStockfish監査で、旧局面 `5r1k/1pp3Rp/8/q7/8/8/1B6/6K1 w - - 0 1` は `Rxc7+` に `...Rf6` で対抗すると白が不利になると分かった。旧教材は「キング移動を選んだ型の実演」と注記していたが、実戦的な練習問題としては不十分だった。

今回はf8の黒ルークをナイトに替え、`5n1k/1pp3Rp/8/q7/8/8/1B6/6K1 w - - 0 1` に変更。序盤の合駒による反証を取り除き、`Rxc7+` の**全合法応手**と最も抵抗力の強い応手を個別に調べた。

| 1.Rxc7+ への応手 | 白の継続 | 教える内容 |
|---|---|---|
| `...Kg8` | `Rg7+ Kh8 Rxb7+` | 風車でチェックを繰り返しポーンを取る |
| `...Qc3` | `Bxc3+` | 黒の合駒を白ビショップが取りクイーンを獲得 |
| `...Qe5` | `Bxe5+` | 別の合駒でもクイーンを失う |

現行チェスルール実装と独立した `python-chess` で、黒の合法応手が上記3通りしかないこと、合駒の2手ともクイーンを失うこと、キング移動で風車が続くことを確認する回帰テストを追加した。さらに、キング移動を選んだ実演の最後は従来の `Rxe5` ではなく、**`Bxe5#` とクイーンを取りながら詰ませる最善の着手**に訂正した。この終局はStockfishとチェスルール実装で確認し、チェックメイト回帰テストの対象にした。

### Stockfish診断

GitHub Actions上の**Stockfish 16**、1回約0.3～0.5秒の探索で旧局面の `Rxc7+` はおよそ -4.3ポーン相当と判定された。一方、新局面の `Rxc7+` は**mate in 4** の有利な候補と判定され、最も抵抗する黒の応手として `...Qc3` が選ばれた。初手の白最短詰み手は `Rg6+` 等であり、`Rxc7+` が唯一・最速の最善手という意味ではない。あくまで風車の形と、最強の反撃を受けても成り立つ攻めを学ぶ教材である。

監査スクリプトに `depth=16` の独立Stockfish検査を追加。実演初手をルート指定した評価が白から見て+500cp以上であることを要求する。ただしエンジンの探索深度による評価は数学的な証明ではない。

探索経過の証拠：<https://github.com/moenium-AI/animal-chess/actions/runs/40171097792> （候補探索ログ）。探索用の一時ファイルは今回のPRには残さない。

## 学習体験

- **メイン再生**は従来の風車（`...Kg8` を選ぶ変化）を維持。
- **比較分岐**を1件追加し、`...Qc3 Bxc3+` という強い受けも見られるようにした。既存12比較から13比較となる。
- 日英の導入、まとめ、棋譜注釈を新しい局面・応手に合わせて修正。教材IDと手数を維持するので学習履歴と保存キーは変更しない。
- `tools/lessons_gen.py` と `tools/lessons_en.py`（教材生成元）を配布用 `js/lessons.js` と同期。
- ブラウザ・Workerキャッシュバージョンを更新。

## 別教材の暫定調査と残課題

`cb_decoy`（おびき出し）では、黒f8のルークをナイト・ビショップ等に置換した試案もStockfishで評価したが、白の攻めの保証は得られなかった。現行教材は相手の誤応手を明示する「失敗から学ぶ」例のまま残す。最善応手で勝てると**表現しない**。

今後は `cb_decoy`、`cb_smother`（スマザーメイト）、`cb_interference`（利きの遮断）を、対最善応手での実例として全面的に再構成する余地がある。短時間Stockfishの大きな評価差だけで、教育上意図した悪手を機械的に置換しない。
