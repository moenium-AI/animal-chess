# 理解度チェックの表現・画面スクロール・関連パズルからの復帰（2026-10-25）

対象：全80教材の学習体験。元の問題文・正答・棋譜・学習済みデータ・AI・パズル内容には変更しない。

## 1. 汎用的で自然な2問の見出し

従来の「🧠 なぜ？どう防ぐ？」と「なぜその手？」「どう防ぐ？」は、実際には防御を問わない問題（例：64マスの教材の初回ポーン2マス移動）と矛盾していた。

| 要素 | 日本語 | English |
|---|---|---|
| コーナー名 | 🧠 考えてみよう | 🧠 Think it through |
| 第1問 | ① ポイント | ① Key idea |
| 第2問 | ② もう一歩 | ② Think further |

この表記なら、座標・基本ルール・手順の結果・詰み・相手の受けなど、160問のどれでも文意の齟齬が生じない。従来の内部キー `why` / `defense` と保存記録 `animalchess_reasoning_v1` はそのまま保持。

## 2. 棋譜を進めてもページが下にずれない

原因は `renderReplayMovelist()` から毎回呼ばれる `Element.scrollIntoView({block:'nearest'})`。これは棋譜リスト以外のスクロール祖先やウィンドウまで移動し得た。

- `scrollInsideList(container, item)` を新設し、**対象がリストの表示範囲から外れた場合だけリスト自身の `scrollTop` を更新**。
- 棋譜の再描画前にリスト内のスクロール位置を保存・復元。加えて、解説や学習進捗の再描画で外側のウィンドウ位置が変化した場合は、`replayGoTo()` 終了時に元の `scrollX / scrollY` に復元する。
- 「一手ためす」で盤面にフォーカスを移すときも `focus({preventScroll:true})` を指定し、ページを動かさない。
- `goToNextPuzzle()` のパズル一覧ジャンプも同じ方式に統一。
- 可変長の学習ノートがブラウザのスクロールアンカーを動かさないよう、`.study-panel` に `overflow-anchor: none` を設定。
- Playwrightで長い風車の教材を一手ずつ進め、戻しても `window.scrollY` が変わらず、**棋譜一覧自体は必要に応じてスクロールする**ことを確認。

## 3. 関連パズルから元の教材へ戻る

以前は `loadPuzzle()` が再生中の注釈を解除していたため、「関連パズル」へ行くと元の教材へ戻る操作がなかった。

- 学習教材から「🧩 関連パズル」を選ぶと、パズル欄の先頭に **「↩ 元の学習に戻る」** を表示する。
- 保存する情報：元の教材と章、通常／比較の別変化、再生位置、途中の「一手ためす」、フィードバック、理解チェックの第1問／第2問と回答・前後盤、元のページスクロール位置。
- パズルを再挑戦したり、別の関連パズルへ進んでも復帰ボタンは維持。戻ればゲーム盤と学習UIを再構築し、途中から再開できる。
- 日本語／英語の切替に応じて復帰ボタンと教材名をローカライズ。
- 新しいゲームや別の教材の開始では、古い戻り先を消去。関連パズル以外から開いたパズルには復帰ボタンを出さない。
- 一時的な復帰状態だけをメモリに保持し、保存済み学習成績やパズルのクリア記録を上書きしない。

## 回帰試験

`tools/test_full_game_browser.py` に以下を追加。

1. 日英の見出しがルール問題にも当てはまること。
2. 基本教材から関連パズルに移動し、元の棋譜・理解チェックの回答・言語切替を維持して戻ること。
3. 途中の「一手ためす」を復元できること。
4. ステイルメイト教材の**別変化の途中**から関連パズルに移っても、選んでいた変化と手数・設問が復元されること。
5. 新しいゲームで古い戻り先が消えること。
6. 11手の教材で一手ずつ進む／戻る際に外側のウィンドウが動かず、棋譜一覧だけがスクロールすること。

GitHub Actionsの既存の全ゲーム／Web Worker／理解チェック回帰も維持。データJSの内容、選択肢、採点ロジックは不変。
