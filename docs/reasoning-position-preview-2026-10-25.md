# 160問の盤面同期と解答後の一手再生（2026-10-25）

## 目的

80教材・160問のうち103問は、問題で問われる手順が2手以上進んだ位置に関係する。これまでは学習リプレイが初期盤面（0手目）から始まり、初心者が「説明の局面」を盤面上で確認しづらかった。

今回、**すべての理解チェックに独立した8×8の確認盤**を設置した。正解の手を解答前に見せずに、実際の合法棋譜から「問題で問われる一手の直前」を表示する。正解したときに、当該の一手を再生した配置へ切り替え、指し手のSANを示し、出発・到着マスを強調する。

### 解答と盤面の流れ

1. レッスンを開くと「なぜその手？」の**一手前の盤面**を表示する。正しい指し手のSANや結果局面はまだ表示せず、「正解の一手を見る」は無効。
2. 誤答しても一手前の配置のまま。誤答のみで達成記録・通常の再生位置を変更しない。
3. 正解したら、問題に対応する合法手を表示。正答の解説が表示され、「一手前に戻る」「正解の一手を見る」の両方で比較できる。
4. 「どう防ぐ？」に切り替えたら新しい設問として一手前を表示する。既に過去に正解したことがあっても、新しい問題を開いた直後は解答を先に見せない。
5. 日本語・英語の切替では、現在の設問・選択状態・プレビュー状態を維持する。ページ再読込では従来どおり解答済みの履歴だけを復元し、盤面は一手前から始める。

## 安全な盤面計算

`js/reasoning_positions.js` は各設問の対象手（0から数える半手インデックス）を明示的に指定し、`Chess` の**新しいインスタンス**で局面を再現。返り値は `beforeFen`、`afterFen`、対象SAN、着手元・着手先。ゲーム進行用のグローバル `game`、`replay.sans`、`replay.idx`、比較分岐、練習モードを変更しない。

- 既存の148問は根拠SAN列を利用。
- 設問専用の根拠SAN列がなかった**初期6教材・12問**にも、合法な専用手順を用意。
- 基本のステイルメイトで `Qf7` と `Qf6+ Kg8`、キャスリングで `O-O` と `Kd2` を比較できる。
- 風車 `...Qc3 Bxc3+`、スマザーメイト `...Rxf7 Qxf7`、おびき出し `...Qd5 Bxd5+`、利きの遮断 `...Bxd6 Rxd6` という**本線と異なる合法変化**にも対応。
- 終盤の `eg_stalemate` では詰みと `Qg6` によるステイルメイト、`eg_triangulation` では三角法と `c6+ Kc8` の違いを実物の盤面で確認できる。
- ルセナの `Rc4`、キングス・インディアンの12半手目 `...e5`、フィリドールの `...Ra1` のように深い手順も、該当の一手に正確に合わせている。

対象手のSAN、着手後FENは**正答までDOMへ配置しない**。通常の棋譜リプレイを手動で進める自由は従来どおり残すが、確認盤はその操作から独立している。

## 見た目とアクセシビリティ

- 盤は最大240px（狭い画面では210px）の控えめな8×8、装飾や光沢を増やさず既存の落ち着いた配色に合わせる。
- 両言語の駒名と手番を含む盤面の説明を `role="img"` と `aria-label` で提供する。
- 元の3択の `role="group"` に `aria-labelledby="study-reasoning-question"` を追加し、読み上げ時に設問との対応を明示。
- 合法棋譜を直接描画するのみで、AIによる局面評価や外部通信は加えない。
- キャッシュ版を更新：`js/reasoning_positions.js?v=1`、`js/app.js?v=31`、`js/i18n.js?v=13`、`css/style.css?v=23`。

## 退行検査

- `tools/test_reasoning_positions.cjs` は**全80教材・160問**の一手前・一手後FEN、実SAN・着手座標、代替変化、無効入力を検査。
- 従来の160問の日英正答・棋譜合法性・長さヒューリスティック検査を継続。
- `tools/test_full_game_browser.py` では、誤答で結果を開示しないこと、正答後の一手・戻し操作、ステイルメイトの別手順、深いオープニング、言語切替、ページ再読込、リプレイカウンタ不変を確認。
- 実HTTP配信のブラウザ検査とWeb Worker、従来のゲーム一式は既存GitHub Actionsで検証する。

## 限界

解答後の再生は、元教材や分岐から**厳密に合法な一手**を提示する機能であり、すべての最善応手を評価するものではない。設問によっては、対象の一手とその後の教材内容が別の戦略上の話題を扱うため、問題文とフォーカス位置の自然さは引き続き学習体験で改善可能。
