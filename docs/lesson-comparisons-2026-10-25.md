# 学習教材の指し手比較（2026-10-25）

## 目的と範囲

「まなぶ」で指定の一手を指すだけではなく、**別の合法な手を選んだら盤面で何が起きるか**を示す。棋力評価の自動生成ではなく、特定の事実が説明できる教材について、日本語・英語で編集した短い分岐を収録する。

- 今回は全80教材のうち**12教材**に比較分岐を追加する。他68教材の既存一手チャレンジ、名局15局は変更しない。
- 教材の本筋は変更しない。「教材の手」「別の一例」で、分岐点とその後の1〜2半手を実際の盤面・棋譜・解説に同期表示する。棋譜の前後ボタンでも移動可能。
- 「教材の手」に戻すと元の全文棋譜が復元される。言語切り替えも、現在選択中の分岐と棋譜位置を保持する。
- 分岐中は**習得・学習済みを付与しない**。「一手ためす」で元の教材に復帰してから回答する。
- 本筋と分岐の比較には具体的な説明を付けるが、**別の合法手が一般に悪手だとは判断しない**。特に定跡・キングの活用では手の狙いの違いを示すだけにする。

## 再現と品質保証

```sh
node tools/test_lesson_comparisons.cjs
node tools/test_intro_lessons.cjs
node tools/test_course_expansion.cjs
python tools/test_full_game_browser.py
```

`tools/test_lesson_comparisons.cjs` は、比較対象のIDの存在、分岐開始半手、全SANの合法性・正規SAN表記・本筋との相違、日本語・英語の非空文章、局面の非破壊性を検証する。特にステイルメイト/王手/キャスリング権/アンパッサン/フォーク/駒取りについて、実際の盤面に一致するかを確認する。ブラウザテストはメイン/別手切り替え、棋譜ナビゲーション、日英切り替え、習得記録維持、演習へ戻る操作を検査する。

### 検証の限界

合法なSANと一部の盤面事実は自動検証できるが、あらゆる応手に対する最善性・勝率・エンジン推奨値・難易度まで保証しない。分岐は各1つの例示であり、全合法手を網羅した変化木ではない。適用範囲を明示し、誤って全代替手を「間違い」と評価するUIにはしない。

旧教材・名局データと従来の保存キー `animalchess_learning_v1` は不変。ゲームエンジン・AIレベルの設定も変更しない。
