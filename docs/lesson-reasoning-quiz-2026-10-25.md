# 理由と防御を考える学習チェック（2026-10-25）

基準main：`16b59032a3a1f34565be9472e902324d08bf0f01`。

## 目的と範囲

従来の「一手ためす」は**教材の指し手を再現できたか**だけを確認する。今回、別の学習体験「🧠 なぜ？どう防ぐ？」を追加し、具体的な局面の狙いと応手を考える**選択式の理解問題**を用意した。

初回は内容を既存の監査・比較分岐で照合できる**6教材・各2問・計12問**、それぞれ3択で日本語・英語に対応する。

| 教材 | なぜ？ | どう防ぐ？ |
|---|---|---|
| `bk_stalemate` | 王手の有無と合法手を区別 | `Qf6+ Kg8` の具体例 |
| `bk_castling` | `O-O` のキング・ルーク位置 | `Kd2` で失うキャスリング権 |
| `cb_windmill` | ビショップの発見王手 | `Rxc7+ Qc3 Bxc3+` の防御と捕獲 |
| `cb_smother` | `Qg8+` による逃げ道の遮断 | `Nf7+ Rxf7 Qxf7` |
| `cb_decoy` | `Nf7+` のキング・クイーンのフォーク | `Bb3+ Qd5 Bxd5+` |
| `cb_interference` | c7で守りの線を遮る | `c7 Bxd6 Rxd6` |

出題は**具体的な例**についての理解に限定し、すべての最善応手を網羅・断言するものではない。暗記ではなく理由の説明を求める一歩として、間違いは再挑戦でき、正答後に初めて正答解説を表示する。

## 操作と学習履歴

- レッスンの既存の盤面・比較・「一手ためす」は変更しない。
- 対象教材の再生パネルに「なぜその手？」「どう防ぐ？」のタブと3択を出す。盤面のどの半手でも操作でき、回答は盤面を変更しない。
- 正解した設問だけ `animalchess_reasoning_v1` に `{lessonId:{why:true,defense:true}}` 形式で保存する。従来の `animalchess_learning_v1` と完全に分離。
- 不正解で履歴は変えない。再回答可能であり、正解後にも設問を読み返して再挑戦できる。
- 同一教材の進度は「理解チェック0〜2/2」、学習章には対象設問数の合計を表示する。
- 言語切替時、設問種類・回答の選択状態を復元。別教材・別ゲームに変われば画面上の一時回答状態を初期化する。
- 保存データは既知のIDと `true` のみ採用。壊れたJSONや余分なキーを無視する。

## 技術と品質

- `js/lesson_reasoning.js` に監査済み設問を独立して定義し、両言語で選択肢のインデックスを一致させる。
- `js/learning.js` の純関数で採点・保存値を検証。
- `tools/test_lesson_reasoning.cjs`：IDと比較教材との対応、日英の3択と解説、正誤、危険な保存値、非破壊更新を検査。
- `tools/test_course_expansion.cjs` から新規テストを呼び出し、既存CIの「教材回帰」で自動実行する。
- `tools/test_full_game_browser.py`：ブラウザ上の誤答・正答・履歴保存・言語切替・比較切替・別教材移動・既存棋譜カウンタ不変を確認する。
- コンテンツ、学習状態、ゲームロジックの旧形式と互換。80教材・15名局とゲームの演出は維持。

## 限界と今後

最初の12問は、既存の教材の狙いを理解するための選択式問題であり、Elo測定でも適応学習アルゴリズムでもない。ヒントを使わず最初の試行で答えたかどうかの採点は行わず、理解チェックは回答した事実を記録する。今後の拡張は、問題の正確性の確認を続けながら段階的に増やす。

CIはPRの最終コミットに対する実行結果で評価する。
