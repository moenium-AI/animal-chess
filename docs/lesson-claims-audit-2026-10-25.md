# 教材の主張監査（2026-10-25、PR #22）

## 対象と方法

GitHub main `22c94f083ae38e2be3d932c9427e04932e053ea1` を基準に、現行の `js/chess.js` の `Chess` クラスで80教材の全368半手を再生した。指し手の合法性、SAN表記の王手・詰みと結果、終局判定を確認した。また、12件の比較データと既存の局面検証・文言を照合し、特に断定的な教育上の主張を読んだ。

結果：全80教材の再生で合法性エラーと王手・詰み表記の不整合はゼロ。終局する例ではチェックメイト12件、ステイルメイト2件（うち1件は誤解を防ぐ教育用の例）、駒不足による引き分け2件を観察した。12件の比較分岐データも存在した。この監査は**全合法応手・エンジン最善手を網羅したものではない**。

## 変更

1. `cb_double` の「王手の二重攻撃は確実に駒得」という一般化を削除し、具体的な応手に条件づけた。掲載手順 `Qa4+ Kf8 Qxh4` は変更しない。
2. `cb_hanging` の「無防備ならただで取れる」という過度の断定を取り、捕獲後の安全と相手の反撃の確認を促す。
3. `eg_opposition` の「ポーンだけでは前に進めない」をこの局面に限定。英語の過度な一般化も修正。
4. 編集元の `tools/lessons_gen.py`・`tools/lessons_en.py` と配布用 `js/lessons.js` に同じ変更を加え、再生成時に戻らないようにした。
5. 比較分岐テストを「10件以上」から既知の12個のID一致へ強化。分岐の誤削除・増減は明示的なレビューが必要となる。

## 保持した事項

- 教材のID、FEN、SAN、注釈の手数、一手チャレンジ、比較分岐、名局と保存キーを変更しない。
- 日本語と英語の意味の整合性を維持。
- 2026-10-16に保存テーブルベースと照合したルセナ・フィリドール・三角法の棋譜と局面は変更しない。

## 未完了の検証

- 80教材すべての全合法応手に対するStockfish評価、および終盤全局面の最新テーブルベース再照会。
- 名局15局の原棋譜・史実照合。
- 今回のコード変更後のGitHub CI・ブラウザー回帰検査（PR実行結果で別途判定）。

この監査は合法性と一部の文言の整合性を強化する限定的な監査であり、全戦略的主張の正しさを保証しない。
