# 学習コース拡張（2026-10-25）

## 目的

既存44教材（オープニング13、戦術17、終盤14）を保持し、チェス初心者が盤の座標から実戦の基本まで自力で学べるようにする。

## 収録

- **はじめて**：14教材。盤とポーン、ルーク、ビショップ、ナイト、クイーン、キング、駒取り、王手、メイト、キャスリング、昇格、アンパッサン、ステイルメイト。
- **基本の考え方**：10教材。中央、展開、受け、キング安全、オープンライン、ピン、フォークの基礎、交換、相手の脅威、簡単な計画。
- **戦術・終盤・オープニング**：従来の44教材をそのまま使用。教材全体68本。
- 日本語と英語に全教材のタイトル・導入・結論・全指し手注釈・演習設問・ヒントを用意。

## 体験

新しい24教材は「解説を見る → 実際に盤面で指定の一手を指す → 理解度を記録する」の形式。誤った手を指しても元の局面を保持し、ヒントを読める。採点は教材で**指定されたSANの再現**であり、別の合法手が一般に悪手であると断定しない。昇格の選択は通常の対局と同じモーダルで行う。

「一手ためす」では指定局面へ戻る。正解なら次の解説へ進み「習得」、最後まで観察しただけの場合は「学習済み」に記録される。習得を学習済みへ降格させない。元のパズル履歴は変更しない。「関連パズル」は該当するテーマの未クリア問題を優先する。

## データと検証

- 既存44件のソースは `tools/lessons_gen.py` / `tools/lessons_en.py`、出力は `js/lessons.js`。
- 新規24件は `js/intro_lessons.js` の独立した追加データ。既存生成器を再実行しても新規データを上書きしない。
- 進捗は `localStorage` の `animalchess_learning_v1` に保存。既知IDと `studied` / `mastered` のみ復元。アカウント・外部通信不要。
- `node tools/test_intro_lessons.cjs` が初期局面・全合法SAN・独立の正解着手・日英同数・アンパッサン・昇格・チェックメイト・ステイルメイト・進捗保存を検査。
- `tools/test_full_game_browser.py` が本物のブラウザで学習／練習／正誤／英日切替／進捗／関連パズルと通常対局を検証。

## 制約と今後

各教材の演習は**指定の一手**を再現する形式。あらゆる代替手の戦略的善悪や、すべての相手の応手を評価する自動コーチではない。既存44件は解説再生と学習済み記録のみで、新24件の一手演習を持たない。個別の分岐反証、体系的な演習の追加、学習成果に基づく推奨レベルは、今後の段階的な改善対象である。
